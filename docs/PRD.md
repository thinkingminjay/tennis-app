# PRD — 서울시 공공 테니스장 빈자리 앱

## 문제

서울시 공공서비스예약 사이트는 같은 테니스장을 "기간 × 코트번호 × 평일/주말·주간/야간" 상품으로 쪼개 보여준다. 상세 달력은 날짜별 `신청수/총모집수`만 보여주고, 시간대(회차)와 회차별 잔여·요금은 **로그인 후 예약하기 → 신청서 화면**에서야 보인다. 여러 코트와 테니스장을 비교하려면 이 과정을 반복해야 하고, 취소로 자리가 났는지는 계속 새로고침해야 안다.

참고 앱 smaxh는 날짜·지역·시간·코트 필터와 코트별 시간 타임라인을 제공하지만 사설 코트만 다룬다.

## 목표

1. 흩어진 상품을 **테니스장 → 코트 → 평일/주말·주간/야간**으로 묶어 한 화면에서 보여준다(사진·기간·요금·접수기간·상태).
2. 코트를 누르면 **서울시 예약 화면**이 앱 안 팝업 웹뷰로 뜨고, 시간 확인과 예약은 사용자가 직접 한다.
3. 관심 테니스장의 **새 상품·접수 오픈·상태 변화**를 푸시로 알린다.

> 2026-10-13 범위 변경: 코트 × 시간 그리드와 빈자리 알림은 **보류**. 서울시 사이트가 자동 조회를 차단하므로, 데이터 제공신청 답을 받은 뒤 서버 데이터로 만든다 (CLAUDE.md "확인 사항").

## 사용자

서울에서 공공 코트를 주 1회 이상 잡는 생활 테니스인. 퇴근 후 직장인, 주말 동호회 총무, 단골 코트가 있는 사람, 처음 공공 코트를 써보는 사람.

## 화면 (1단계 앱)

1. **홈**: 상단 칩(평일/주말, 주간/야간, 지역, 요금, 접수중만) + 테니스장 카드 목록(사진, 이름, 자치구·거리, 요금, "접수중 n개" 배지). 서버 데이터만 사용, 로그인 불필요.
2. **테니스장 상세**: 사진, 코트 목록(코트마다 평일/주말·주간/야간 상품, 이용기간, 상태, 접수기간), 요금표, 선착순/추첨, 취소 규칙, 주소·전화, "마지막 갱신" 시각.
3. **예약 팝업**: 코트(상품)를 누르면 서울시 예약 화면을 앱 안 웹뷰 팝업으로 연다. 로그인·시간 확인·예약·결제는 사용자가 서울시 화면에서 직접 한다. 앱은 아이디·비밀번호를 받지 않고 화면 내용을 읽지 않는다.
4. **알림 만들기**: 테니스장(복수) → 코트(전체/특정) → 평일/주말·주간/야간 → 이벤트(새 상품, 접수 오픈, 상태 변화).
5. **알림 탭**: 알림 조건 목록(켜기/끄기) + 받은 알림 기록.
6. **지도**: 테니스장 핀 + 접수중 상품 여부.
7. **내 정보**: 즐겨찾기, 방해금지 시간, 웹뷰 로그인 정보 지우기(쿠키 삭제), 출처·비공식 문구, 마지막 갱신 시각.

## MVP 범위

| 기능 | 단계 |
| --- | --- |
| 테니스장 목록·사진·지도·필터 | 1 |
| 코트별 상품 정보(기간·요금·상태·접수기간) | 1 |
| 서울시 예약 화면 팝업 웹뷰(사용자가 직접 로그인·예약) | 1 |
| 새 상품·접수 오픈·상태 변화 알림, 즐겨찾기 | 1 |
| 모바일 웹 (상품 정보 + 서울시 새 탭) | 2 |
| 코트×시간 그리드, 날짜·시간 단위 빈자리 알림 | 보류 — 서울시 데이터 제공 후 |
| 이벤트·공지 알림, 빈자리 패턴 통계, 구청 코트 | 3 |
| 앱 내 결제, 자동 예약 | 하지 않음 |

## 알림 규칙

- 같은 조건의 이벤트는 10분 단위로 묶어 한 번만 보낸다.
- 밤 11시~아침 7시 방해금지(끌 수 있음).
- 모든 알림에 서울시 예약 페이지 딥링크.
