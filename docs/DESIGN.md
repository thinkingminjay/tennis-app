# 디자인 원칙

- 참고: smaxh 앱 (사진이 들어간 카드 목록, 상단 필터 칩, 코트별 가로 시간 타임라인, 하단 고정 예약 버튼).
- 깔끔하고 밝은 화면, 다크모드 지원. 포인트 컬러 하나로 "접수중" 상품을 강조하고 예약마감·접수종료는 회색.
- 상세 화면: 코트별 행, 행 안에 평일/주말·주간/야간 상품 칩(상태색 + 이용기간). 칩을 누르면 서울시 예약 화면 팝업.
- ~~코트 × 시간 그리드~~: 보류(2026-10-13). 서울시 데이터 제공 후 다시 설계한다.
- 목록·상세에 "n분 전 갱신"(오픈API 수집 시각)을 붙인다.
- 예약 팝업 상단에 "서울시 예약 화면입니다. 예약은 직접 진행해 주세요" 안내와 닫기 버튼.
- 하단 탭: 홈 · 지도 · 알림 · 내 정보.
- 문구는 짧은 존댓말. 서울시 로고·명칭을 브랜드처럼 쓰지 않는다.
- 세부 비주얼은 1단계 중반에 다시 조정한다(오너 결정).
- 1단계 첫 화면(2026-10-13): Lazyweb 참고(fixtured 종목 칩+목록, StubHub·Fever 지도 핀+하단 카드). 홈 카드는 사진 대신 상태색 아이콘을 쓰고, 테니스장 사진은 상세 화면에서만 1장 불러온다(앱을 열 때 서울시 서버로 이미지 요청이 몰리지 않게).
- 1차 비주얼 정리(2026-10-20, 유아이볼 참고: 카카오골프예약 예약 화면, 볼트업 지도 하단 카드, 마이리얼트립 목록, 빽다방·달다방 알림 설정):
  - 연회색 바탕(`page`) 위에 흰 카드(`card`) 묶음. 목록 행은 테두리 대신 카드 안 구분선.
  - 홈 목록 위에 "총 n곳 · 접수중 m곳", 카드 아랫줄에 "접수중 3 / 12" 비율.
  - 상세 상단에 회색 숫자 타일 3개(접수중·전체 상품·요금)와 '접수중' 뜻 안내 박스.
- 포인트 컬러 주황으로 변경(2026-10-20, 사용자 요청): 접수중·버튼·지도 핀은 주황(`accent`), 겹치지 않게 안내중(`soon`)은 파랑으로 바꿈.
- 코트 바닥 색(2026-10-21): 하드 남색, 클레이 주황, 인조잔디 초록, 모름 회색. 여러 종류면 세로로 나눠 칠함(하드+클레이 = 왼쪽 남색·오른쪽 주황). 홈 테니스공 아이콘·지도 코트 핀·상세 '바닥' 줄에 적용. 지도 핀은 접수중이 없으면 흐리게. 재질은 수집기가 오픈API 안내문에서 단어로 추정한 값이라 틀릴 수 있음.
- 포인트 컬러 Morning Yellow(2026-10-21, 사용자 요청): 면(버튼·스위치·지도 '상세 보기')은 `accent` #FFC93C, 흰 바탕 위 글자·작은 아이콘은 읽히도록 `accentText` #8A6400. 홈 아이콘 배경은 재질 색 빗금(공과 같은 비율로 세로 분할).
  - 지도 하단 카드: 지역 → 이름 → "접수중 n/m" 타일 + "상세 보기" 버튼.
- 알림 조건·예약 팝업 정리(2026-10-22, 유아이볼 참고: 토스증권·코빗 알림 설정): 알림 조건은 회색 바탕 위 흰 카드, 테니스장은 오른쪽 원형 체크, 받을 소식은 제목+설명+스위치. 예약 팝업은 왼쪽 닫기(X)·가운데 제목·오른쪽 '브라우저에서 열기' 원형 버튼, 그 아래 노란 안내 박스와 로딩 막대.
- 시작 화면(2026-10-14, 유아이볼 참고: 앳플리 단색 바탕+가운데 심볼): Morning Yellow 바탕 가운데 먹색 테니스공(노란 솔기). 다크모드도 같은 화면. Expo Go에서는 보이지 않고 실제 빌드에서만 보인다.
- 웹뷰 로그인 정보 지우기(쿠키 삭제)는 네이티브 모듈이 필요해 EAS 빌드 이후로 미룬다.

## 디자인 MCP 사용법

`.mcp.json`에 무료로 쓸 수 있는 서버만 등록했다(Mobbin·Nicelydone·Refero는 유료라 제외, 2026-10-13 오너 결정).

| MCP | 용도 | 인증 |
| --- | --- | --- |
| Lazyweb | 디자인 리서치 리포트 | 토큰(`LAZYWEB_TOKEN`), 무료 계정은 일부 리포트만 |
| Inspo | 웹사이트 컴포넌트·색·타이포 | 키 없음(무료 호스팅) |
| 유아이볼(uibowl) | 국내 앱 실제 화면(패턴·컴포넌트·앱별) | claude.ai 커넥터, 무료는 검색당 3건 |

검색 예: "court list with status chips", "in-app browser sheet header", "filter chips date picker mobile", "venue list card with photo".
