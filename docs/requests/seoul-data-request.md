## 1. 공공데이터포털 "공공데이터 제공신청"

- 위치: data.go.kr → 데이터 요청 → 공공데이터 제공신청
- 제공기관: 서울특별시 (관리부서: 정보시스템과 — 서울시 공공서비스예약 정보 OpenAPI 관리부서)

**신청 데이터명**
서울시 공공서비스예약 체육시설(테니스장) 일자별·회차별 예약 현황

**요청 항목**
| 항목 | 설명 |
| --- | --- |
| rsv_svc_id | 서비스ID (기존 OpenAPI의 SVCID와 같은 값) |
| 이용일 | YYYYMMDD |
| 회차 번호, 시작·종료 시각 | 예: 회차1 06:00~08:00 |
| 신청수 / 모집정원 | 회차별, 일자별 합계 |
| 예약 가능 여부 | 접수 가능·마감·휴관 등 |
| 회차별 요금 | 일반/감면 구분이 있으면 함께 |

**제공 형태**
기존 "서울시 공공서비스예약 정보"(OA-2266)처럼 OpenAPI(JSON). 가능하면 실시간 또는 5~10분 갱신. 어렵다면 하루 1회 파일 제공도 좋음.

**활용 목적**
서울시 공공 테니스장의 빈 회차를 한눈에 보여주고, 사용자가 원하는 회차가 비면 알려주는 무료·비영리 모바일 앱. 예약과 결제는 앱이 대신하지 않고 서울시 공공서비스예약 사이트로 연결한다. 출처(서울특별시, 공공누리 1유형)와 "비공식 앱"을 표시한다.

**신청 사유 (참고 문구)**
현재 이 정보는 예약 사이트 상세 화면에서 사람이 볼 수 있지만 OpenAPI로는 제공되지 않습니다. 사이트에 봇 차단이 적용되어 있어 기계적 수집은 하지 않으려 합니다. 공식 데이터로 제공해 주시면 사이트 부하 없이 시민에게 빈자리 정보를 안내할 수 있습니다.

## 2. 서울시 정보시스템과(공공서비스예약 운영) 문의

- 경로: 서울시 공공서비스예약 사이트 고객센터 / 응답소(eungdapso.seoul.go.kr) 민원, 또는 다산콜 120에 담당부서 확인
- 목적: 1번이 결정되기 전까지, 공개 달력(날짜별 신청수/모집수)을 **허락받은 방식으로** 받을 수 있는지 문의

**문의 내용 (초안)**

> 안녕하세요. 서울시 공공 테니스장 빈자리를 안내하는 무료·비영리 앱을 준비하고 있습니다.
> 예약 사이트 상세 화면의 공개 달력(날짜별 신청수/모집수)을 앱에서 안내하고 싶은데, 사이트에 비정상 접근 차단이 적용되어 있어 임의로 수집하지 않고 먼저 문의드립니다.
>
> 1. 공개 달력 정보를 제공받을 수 있는 공식 경로(OpenAPI, 파일, 제휴 등)가 있는지
> 2. 없다면, 아래 조건으로 서버 수집을 허락해 주실 수 있는지
>    - 접수중인 테니스장 상품만, 10분에 1회, 순차·초당 1건 이하
>    - 연락처를 넣은 User-Agent와 고정 IP(국내) 사용, 요청 시 즉시 중단
>    - 로그인 정보·개인정보는 다루지 않음
> 3. 앱에서 예약 화면으로 연결(링크)하는 것에 문제가 없는지
>
> 공공데이터포털에 제공신청도 함께 넣었습니다(접수번호: ____). 검토 부탁드립니다.
