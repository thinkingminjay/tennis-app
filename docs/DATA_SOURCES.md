# 데이터 출처

> 작성 환경에서 openapi.seoul.go.kr과 yeyak.seoul.go.kr에 접속할 수 없었다. 아래 필드명과 요청 구조는 **0단계에서 실제로 확인**해야 한다.

## A. 서울 열린데이터광장 오픈API (서버 수집, 합법·안전)

- 데이터셋: [서울시 체육시설 공공서비스예약 정보 (OA-2266)](https://data.seoul.go.kr/dataList/OA-2266/S/1/datasetView.do)
- 라이선스: 공공누리 1유형 (출처 표시, 상업적 이용·변경 가능)
- 갱신: 비정기(수시)
- 예상 서비스명: `ListPublicReservationSport`, 호출 형식 `http://openapi.seoul.go.kr:8088/{KEY}/json/ListPublicReservationSport/{start}/{end}/` (확인 필요)
- 예상 필드(확인 필요): 서비스ID(SVCID), 대/소분류(MAXCLASSNM/MINCLASSNM=테니스장), 서비스명(SVCNM), 접수상태(SVCSTATNM), 결제방법(PAYATNM 유료/무료), 장소명(PLACENM), 이용대상, 서비스 URL(SVCURL), 좌표(X/Y), 이용기간(SVCOPNBGNDT/SVCOPNENDDT), 접수기간(RCPTBGNDT/RCPTENDDT), 지역명(AREANM), 이미지(IMGURL), 상세(DTLCONT), 전화(TELNO), 이용시간(V_MIN/V_MAX), 취소기준(REVSTDDAYNM/REVSTDDAY)
- 쓰임: 테니스장·코트·상품 목록, 신규 상품 감지, 사진, 딥링크
- 주기: 1시간, 접수 시작 전후에는 10분

## B. 예약 사이트 상세 화면 공개 달력 (서버 수집, 공개 화면)

> **2026-10-13 보류.** 달력 Ajax(`selectListReservCalAjax.do`)에 봇 차단(dynapath)이 걸려 있다. 서버식 요청 1건으로 확인한 결과 302 차단 페이지로 이동했다. 서버 수집을 하지 않는다. 서울시에 공식 제공·수집 허락을 요청한 뒤 결정한다. 자세한 내용: POC.md 결과, `docs/requests/seoul-data-request.md`.

- URL 예: `https://yeyak.seoul.go.kr/web/reservation/selectReservView.do?rsv_svc_id={SVCID}`
- 로그인 없이 날짜별 `신청수/총모집수`가 보인다(예: 30일 5/6 → 회차 1개 남음).
- 달력 데이터가 HTML에 박혀 있는지, 별도 요청(XHR)으로 오는지 확인 필요.
- 주기: 접수중 상품만 10분, 알림 구독이 있는 상품은 3~5분. 지난 날짜는 수집하지 않음.
- 요청: 순차, 초당 1건 이하, 연락처가 있는 User-Agent.

## C. 신청서 화면 회차 목록 (기기에서만, 사용자 세션)

> **2026-10-13 보류.** 서울시 사이트가 개발자도구·자동화를 "비정상적인 접근"으로 차단하므로, 숨은 웹뷰로 회차를 불러오지 않는다. 회차 요청 구조도 조사하지 않는다. 서울시 데이터 제공신청(D) 결과가 나오면 서버 데이터로 구현한다. 그전까지 앱은 코트를 누르면 서울시 예약 화면을 웹뷰 팝업으로 띄우고, 사용자가 직접 시간을 보고 예약한다. 아래 내용은 기록용.

- URL: `https://yeyak.seoul.go.kr/web/reservation/insertFormReserve.do` (로그인 필요, 2026-10-13 사용자 확인: 로그아웃 시 로그인 화면으로 이동)
- 날짜 선택 시 회차 목록이 표시된다: `06:00~08:00 (1/1) 회차1` … `16:00~18:00 (1/1) 회차6`, 요금(예: 일반 8,000원)
- 이 목록을 불러오는 요청(XHR URL, 파라미터, 응답 형식)을 0단계에서 확인한다.
- 앱의 숨은 웹뷰가 **사용자 본인 세션**으로, **화면이 열려 있을 때만**, 코트 상품마다 간격을 두고 요청한다. 결과는 기기 메모리/로컬 캐시에만 둔다.

## D. 서울시 데이터 제공 요청

- 공공데이터포털 "공공데이터 제공신청"으로 서울특별시에 신청. 10일 내 결정(10일 연장 가능), 거부 시 60일 내 공공데이터분쟁조정위원회 조정 신청.
- 요청 내용: 상품(rsv_svc_id)·이용일·회차별 시작/종료 시각, 신청수, 모집정원, 회차별 요금. 오픈API(JSON), 가능하면 실시간 또는 5~10분 갱신.
- 받으면 C를 서버 수집으로 바꾸고 **시간 단위 알림**을 추가한다.

## 법·약관 메모 (법률 자문 아님)

- 공개 화면이라도 과도한 수집은 부정경쟁·데이터베이스권 침해로 민사 책임을 진 국내 사례가 있다. 로그인·보안조치 우회는 형사 문제가 될 수 있다.
- 출시 전: 서울시 이용약관과 robots.txt 원문 저장, 간단한 법률 상담.
- 서울시가 문제를 제기하면 즉시 B 수집을 멈추고 A만으로 운영한다.
