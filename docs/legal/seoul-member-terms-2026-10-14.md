# 서울시 통합회원 이용약관 검토 (2026-10-14, 법률 자문 아님)

공공서비스예약 로그인에 쓰는 서울시 누리집 통합회원 약관이다. 시행일은 2026-08-31이고, 사용자가 회원가입 화면에서 직접 복사해 확인했다.
아래 요약은 원문 문구가 아니며, 정확한 내용은 원문을 따른다.

이 약관은 **회원**(서울시에 가입한 사람)과 서울시 사이의 약속이다. 이 앱은 서버에서 로그인하지 않고, 데이터는 열린데이터광장 Open API에서만 받는다(별도 약관: `seoul-openapi-terms-2026-10-14.md`). 그래서 대부분 조항은 앱 사용자가 웹뷰에서 직접 로그인해 예약할 때 적용되고, 앱 운영자에게 직접 걸리는 부분은 아래 표에 정리했다.

| 조항 | 요지 | 이 앱에서 |
|---|---|---|
| 제12조 ③ | 서비스로 얻은 정보를 가공·판매하거나, 게재된 자료를 영리 목적으로 쓰거나 제3자에게 제공 금지 | 예약 사이트 화면·로그인 후 정보는 읽지도 수집하지도 않는다. 공개 데이터는 Open API(공공누리 1유형)로만 받는다. **무료·비영리 운영 유지**. 광고나 유료화를 하려면 먼저 법률 상담 |
| 제13조 | 서비스·로고·마크·디자인·서비스 명칭은 서울시 것. 승인 없이 수정·배포·상업적 이용 금지 | 서울시 로고, "공공서비스예약" 같은 서비스 명칭을 앱 이름·아이콘·화면 디자인에 쓰지 않는다. 출처 표기는 "서울특별시 공공데이터"로 한다 |
| 제14조 ③ 3호 나 | 서울시 사전 승낙 없이 서비스를 이용한 영리 활동 금지 | 제12조 ③과 같은 이유로 비영리 유지 |
| 제14조 ③ 3호 라 | 업무 방해, 안정적 운영 저해 금지 | 자동 예약·매크로 없음, 예약 사이트 자동 접속 없음(CLAUDE.md) |
| 제14조 ③ 1호 가·마 | 타인 계정 도용, 다른 회원 개인정보 수집 금지 | 아이디·비밀번호를 받지 않고, 기기 데이터를 올리지 않는다 |
| 제14조 ② 2호 | 회원은 접속을 마치면 로그아웃해야 함 | 회원의 의무. 나 탭 '로그인 유지'를 끄면 웹뷰에 로그인이 남지 않는다. 공용 기기에서는 끄도록 안내할 수 있다 |
| 제22조 | 이용 권한을 남에게 양도 금지 | 대리 예약·계정 공유 기능을 만들지 않는다 |
| 제23·24조 | 무료 서비스 손해, 서비스로 얻은 자료로 인한 손해는 서울시가 책임지지 않음 | 앱 데이터는 참고용이고 실제 상태는 예약 화면에서 확인하도록 안내 유지 |

## 결론

- 지금 구조(Open API만 수집, 웹뷰는 그냥 열기만, 비영리, 서울시 로고·서비스명 미사용)는 이 약관과 부딪히는 부분이 보이지 않는다.
- 가장 조심할 것은 **영리화**(제12조 ③, 제13조 ②, 제14조 ③ 3호 나). 광고·유료 기능을 붙이기 전에는 반드시 법률 상담을 받는다.
- 출시 전 간단한 법률 상담은 여전히 권장.
