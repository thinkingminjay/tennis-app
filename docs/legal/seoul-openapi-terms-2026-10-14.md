# 서울 열린데이터광장 이용약관 요약 (2026-10-14 확인, 법률 자문 아님)

원문: https://data.seoul.go.kr/etc/accessTerms.do (시행 2021-09-24). 아래는 요약이며, 정확한 문구는 원문을 따른다.

| 조항 | 내용 | 이 앱에서 |
|---|---|---|
| 제11조 | 저작자·출처 표시 조건의 자유이용이 원칙. 제3자 저작권 데이터는 그 권리자 조건을 따름 | 데이터셋은 공공누리 제1유형(상업적 이용·변경 가능) |
| 제10조 ③ | 결과를 보여 주는 화면에 "서울특별시 공공데이터"를 사용한 결과임을 표시 | 홈·상세 하단, 나 탭에 "서울특별시 공공데이터" 표기 (2026-10-14 반영) |
| 제10조 ② | 데이터 저작권은 서울시에 남고, 이용자가 만든 프로그램은 이용자 것 | - |
| 제7조 ① | 인증키는 본인만 사용, 공유·공개 금지 | 키는 GitHub Secrets와 로컬 .env에만 둔다. 앱에 넣지 않는다 |
| 제6조 ②③, 제8조 ② | 위반·비정상 이용·과도한 트래픽이면 키 정지. 이용 횟수 제한 가능 | 10분마다 순차 호출, 1초에 1건 이하 |
| 제6조 ④ | 트래픽이 많으면 활용사례 등록을 요구할 수 있음 | 요구가 오면 등록. 출시 때 미리 등록하는 것도 검토 |
| 제6조 ② | 데이터를 임의로 위조·변조 금지 | 상품명·상태는 원문대로 보여 주고, 앱이 붙인 정보(코트 바닥 등)는 따로 표시 |
| 제8조 ③ | 선정적·폭력적·혐오 콘텐츠와 함께 배치 금지 | 해당 없음 |
| 제9조 ② | 서울시를 대리하는 것처럼 보이게 하면 안 됨 | "비공식 앱" 표기, 서울시 로고·이름을 앱 이름에 쓰지 않음 |
| 제12조, 제14조 | 데이터 품질·중단으로 생긴 손해는 서울시가 책임지지 않음 | 앱 안내에 "실제 예약 상태는 예약 화면에서 확인" 유지 |

약관에 호출 횟수 상한, 서버 저장, 푸시 알림에 대한 별도 조항은 없다.

## 아직 남은 것

- 공공서비스예약 사이트 자체 이용약관: 회원가입 화면에 있어 자동으로 열지 않는다(CLAUDE.md). 사용자가 직접 브라우저로 열어 내용을 저장해야 한다.
- 출시 전 간단한 법률 상담.
