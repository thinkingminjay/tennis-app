## 결과

### 2026-10-13 — 1차 (로그아웃 상태, 국내 맥에서 확인)

**접속**: openapi.seoul.go.kr, yeyak.seoul.go.kr 모두 이 환경에서 정상 접속(HTTP 200).

**A. 오픈API** (인증키 `sample`로 5건만 확인. 전체는 발급 키 필요)
- 호출 형식 확인: `http://openapi.seoul.go.kr:8088/{KEY}/json/ListPublicReservationSport/{start}/{end}/`
- 응답 `list_total_count: 644` — 테니스장만이 아니라 **체육시설 전체**. MINCLASSNM으로 거른다.
- 실제 필드명: GUBUN, SVCID, MAXCLASSNM, MINCLASSNM, SVCSTATNM, SVCNM, PAYATNM, PLACENM, USETGTINFO, SVCURL, X, Y, SVCOPNBGNDT, SVCOPNENDDT, RCPTBGNDT, RCPTENDDT, AREANM, IMGURL, DTLCONT, … (DATA_SOURCES.md 예상과 일치)
- 날짜 형식: `2025-12-01 00:00:00.0`
- 상품명이 예상과 다른 형태도 있다: `테니스장1(평일)-2026년 응봉공원(대현산배수지)` → 파서는 여러 패턴을 받아야 함
- DTLCONT에 요금·예약 규칙 원문이 있다. 예: "5초이내 예약건은 비정상예약으로 간주, 직권 취소 가능"

**B. 상세 화면 달력** (`selectReservView.do`)
- 달력은 HTML에 박혀 있지 않고 **XHR**로 온다: `POST /web/reservation/selectListReservCalAjax.do`, 본문 = `#aform` 직렬화(rsv_svc_id, yyyy, mm, use_time_unit_code, tme_ty_code 등), 응답 JSON
  - `resultListDays[].{YMD, SVC_RESVE_CODE}`, `resultListTm[YMD].{RCEPT_POSBL_YN, RESVE_POSBL_CNT, REG_TOTAL_CNT, RCRIT_NMPR_CNT}`
- ⚠️ **이 요청에는 봇 차단 솔루션(dynapath, 2025-03-20 적용)이 걸려 있다.** 보호 대상: `selectListReservCalAjax.do`, `selectAllTimeCheckAjax.do`, `selectListReservCalUnitAjax.do`(이름상 회차 목록 후보). 비정상 요청이면 "비정상 접근으로 인한 차단" 화면으로 보낸다.
- 차단 우회로 볼 수 있으므로 **서버에서 이 엔드포인트를 직접 호출하는 테스트는 하지 않았다.** → 서버 수집 B 방식은 재검토 필요 (오너 결정 대기)
